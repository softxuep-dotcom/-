# Fling Fiasco

A portrait-first 3D ragdoll physics comedy game built with TypeScript, Three.js,
Rapier and Vite.

Play the current release: <https://softxuep-dotcom.github.io/-/>

## Local development

```sh
npm ci
npm run dev
```

## Validation and release

```sh
npm run test:all
npm run test:e2e
npm run build
npm run release
```

See `docs/QA_REPORT.md` for the verified release evidence and
`docs/PLATFORM_TEST_GUIDE.md` for owner-only platform checks.
